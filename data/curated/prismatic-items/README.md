# 26.15 棱彩装备表

`26.15.json` 保存 26.15 当前可用的 48 件斗魂竞技场棱彩装备。装备池由 Riot Data Dragon 16.15.1 中竞技场地图（30）、可购买且基础价格为 2750 的装备确定，并保存可结构化读取的静态属性。

不能按连续 ID 范围推断装备品质：`447100`～`447123` 中混有普通装备，例如 `447111` 霸王血铠；部分棱彩装备则使用 `226xxx`、`443xxx`、`444xxx` 或 `446xxx` ID。

静态生命、攻击力、法强、护甲、魔抗、攻速、暴击和移动速度来自 Data Dragon。Data Dragon 会裁剪部分动态 tooltip 数值，因此射手样本中最常见的 6 件装备另由同版本 CommunityDragon `game/items.cdtb.bin.json` 补充适应之力、乘算攻速和伤害效果：断筋者、狂风之力、收割者的过路费、神圣之剑、爆鸣、海克斯弹丸配枪。来源和已建模装备 ID 记录在 JSON 的 `combatEffectSource` 中；其余装备仍只计算已验证的静态属性。

`kr-26.15-100-selection-probabilities.json` 是韩服 100 场样本按英雄主类别统计的经验选择分布。每名可识别玩家贡献总权重 1；若最终保留多件棱彩装备，则在这些装备间均分，避免存活更久的玩家获得更高总权重。它表示玩家归一化的最终保留频率，不是官方提供概率或第二回合首选率。
