# 26.15 棱彩装备表

`26.15.json` 保存 26.15 当前可用的 21 件斗魂竞技场棱彩装备。装备资格按 `data/sources/league-wiki/26.15/prismatic-item-ids.json` 中固定的 League of Legends Wiki `Prismatic items` 分类快照核验，再使用 Riot Data Dragon 16.15.1 装备表中的 Arena ID、中文名和结构化属性。

不能按连续 ID 范围推断装备品质：`447100`～`447123` 中混有普通装备，例如 `447111` 霸王血铠；部分棱彩装备则使用 `226630`、`443xxx` 或 `444644` ID。目录必须使用经过核验的显式 ID 清单。

当前计算模型只录入装备表可直接验证的静态生命、攻击力、法强、护甲、魔抗、攻速和暴击属性。装备被动、技能急速以及 Data Dragon `stats` 未结构化提供的属性不会猜测或手工编造，后续应从客户端结构化数据补充。
