# 斗魂双抗分组统计

这里保存从 Riot Match-V5 Timeline 样本加工出的“英雄主类别 × 回合”护甲、魔抗统计。

- 英雄类别采用同版本 Data Dragon 的第一个 `tags` 标签，形成互斥分类。
- 每组提供观测数、比赛数、英雄数、均值、中位数、P25 和 P75。
- Timeline 没有直接的回合开始事件；当前使用“同一帧至少 3 名玩家同步升级”识别新回合，
  并只统计该帧实际升级的存活玩家。详细规则记录在结果 JSON 的 `methodology` 中。
- 标准玩家在第 12 回合达到 18 级。此后主要使用“至少 3 人生命从非满恢复且当前资源已满”
  识别边界；若只有 2 人满足，还需要至少 3 人同步获得不低于 1000 总金币。
- 金币绝不单独触发回合。满级后的结果按触发信号所在队伍补齐队员，但仍比第 1～12 回合
  置信度低，完整证据保存在结果 JSON 的 `boundaryEvidenceByMatch`。
- CSV 适合人工查看或导入表格，JSON 供计算器直接使用。

输出同时包含两种粒度：

- `resistances-by-category-and-round.*`：英雄主类别 × 回合。
- `resistances-by-champion-and-round.*`：具体英雄 × 回合。

具体英雄表会保留英文名、中文名、主类别、样本数和置信度。单英雄样本明显少于大类样本，
使用时应优先检查 `observations` 和 `matches`。
